# Project 01: Calculator 🧮

## Status: 🟡 In Progress

This is the placeholder directory for the **Calculator** application, the first project in the "40 Web Projects" collection.

---

### Planned Features
- [ ] Standard arithmetic calculations (+, -, *, /, %, ±)
- [ ] Decimal point handling and floating-point precision formatting
- [ ] Scientific / advanced functions (square root, power, brackets, constants)
- [ ] Keyboard input support with visual keypress feedback
- [ ] Calculation history log with recall/clear capability
- [ ] Responsive, tactile UI inspired by modern design systems
- [ ] Dark and light theme modes

### Architecture Plan
- **Framework**: React + Vite (or Vanilla TypeScript)
- **Styling**: Tailwind CSS with custom mechanical button interactions
- **State Management**: Clean calculation state machine handling operands, operators, and edge cases (divide by zero, overflow)

### Development
Once active implementation starts:
```bash
# From this directory:
npm install
npm run dev
```
